# ReadIndia — Book Storefront

React book catalogue with book detail pages, account interfaces and book management dashboard.

## Project structure

- `src/pages/`
- `src/admin/BooksManagement.jsx`
- `db.json`

## Getting started

```bash
git clone https://github.com/JAYANTI-THAKOR-941/ReadIndia.git
cd ReadIndia
```

Install dependencies with `npm install`, configure the local JSON API if required, then run `npm run dev`.
